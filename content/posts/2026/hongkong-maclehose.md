3月中旬，趁着天气还算凉爽，和朋友一起去香港走了麦里浩径。

这条徒步路线非常有名，曾上榜过 National Geographic 的全球最佳徒步路线。

我们的计划是一日游，当日往返，时间和行程大致如下：

| 时间          | 行程                          |
| ------------- | ----------------------------- |
| 09:15         | 从福田口岸出入境出发          |
| 09:30         | 抵达落马洲，乘地铁到大学站    |
| 09:40         | 换乘出租车 ，前往万宜水库东坝 |
| 10:20         | 抵达东坝，开始徒步            |
| 10:40 - 12:00 | 游玩破边洲                    |
| 13:00 - 16:00 | 游玩浪茄湾                    |
| 16:50 - 18:00 | 原路返回大学站，逛了沙田中心  |
| 19:00         | 返回深圳                      |

<!--more-->

天气晴朗，沿途很适合拍照。

![破边洲](https://static.looechao.com/2026/maclehose-ppc.jpg)

![浪茄湾](https://static.looechao.com/2026/maclehose-lkw.jpg)

![I can watch this forever](https://static.looechao.com/2026/hongkong-lkw.gif)

我之前没去过沙滩，所以抵达浪茄湾的时候感觉非常震撼；
在阳光和海风下，面朝着不断拍打岸边的海浪，听着海的白噪音，整个人都放松下来了。

返程的时候，我们在沙田中心吃了 KFC，香港这边的香菇盖饭非常好吃。之后又在新城市广场逛了很久，这边的店很多，也很适合购物。

![贝壳](https://static.looechao.com/2026/seashell.jpg)

整个旅程里，唯一不太舒服的是去东坝那段山路弯多且窄，坐出租车时会比较摇晃，再加上我前一晚休息得不太好、早上起得又早，所以晕车感受比较明显，应该提前准备点晕车贴的。
